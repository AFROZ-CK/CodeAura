# CodeAura

A social coding platform featuring:
- Coding reels (short code videos/snippets)
- Daily code challenges
- Public and private code posts
- Leaderboards and user ranks
- Job/resource sharing

## Feature Suggestions
- Comments/likes on posts
- Direct messaging
- Notifications and personalized dashboard
- Built-in code editor
- External job API integration

## How To Test/Run Locally

### Backend
```bash
cd backend
npm install
npx ts-node-dev index.ts
# Server starts at http://localhost:4000
```

### Frontend
```bash
cd frontend
npm install
npm start
# App starts at http://localhost:3000
```
